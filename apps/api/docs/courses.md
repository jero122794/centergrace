# Courses and Lessons

## Purpose

Curriculum authoring with optional modules, TipTap JSON body (required) and optional YouTube metadata resolved via oEmbed.

## Endpoints

- `GET/POST /api/courses`
- `GET /api/courses/:id`
- `GET /api/courses/:id/progress`
- `POST /api/courses/:id/modules`
- `POST /api/courses/:id/lessons`
- `POST /api/courses/:id/enroll`
- `PATCH /api/courses/:id/scope` (Admin)
- `POST /api/lessons/:id/complete`
