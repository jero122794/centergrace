# Worship module

Repertoire, rehearsals and the four-stage audition pipeline (application → school → audition → active). Chord transposition is a frontend concern.

## Endpoints

- `GET/POST /api/worship/songs`
- `GET/POST /api/worship/rehearsals`
- `PATCH /api/worship/rehearsals/:id/songs/:songId`
- `POST/GET /api/worship/auditions`
- `PATCH /api/worship/auditions/:id`
